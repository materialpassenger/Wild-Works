# 第二课作业感悟
环境：双系统 Ubuntu 22.04；Agent工具：Codex CLI
本次作业借助Codex Agent辅助搭建Ubuntu 22.04环境，并练习基础Linux命令。
在使用Agent时遇到了不少问题：最开始误将对话指令直接粘贴到PowerShell执行；Codex仅启动WebSocket后端，没有内置网页交互界面，尝试在线WebSocket工具还出现参数无法识别、连接断开等故障。通过排查报错信息，我理解了该Agent服务的工作方式。
之后我完成Ubuntu双系统安装，练习pwd、cd、mkdir、cat等目录定位、文件创建、文本查看命令。本次实践让我认识到Agent能够提供方案指导，但需要人工甄别报错、动手调试，熟悉了Linux基础操作，也体会到AI辅助工具的优势与局限。
